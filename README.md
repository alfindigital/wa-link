# WA-Link — WhatsApp Link Generator

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![TypeScript](https://img.shields.io/badge/TypeScript-5-3178c6?logo=typescript)](https://typescriptlang.org)

Buat link WhatsApp `wa.me` langsung dari browser — tanpa simpan nomor, tanpa login. Masukkan nomor + pesan opsional, klik, selesai.

---

## Fitur

- 🔗 **Instant wa.me link** — Generate dan buka langsung
- 📋 **Copy & share** — Salin link atau QR code
- 🕓 **Riwayat** — Simpan nomor yang sering dipakai (lokal)
- 🌐 **No backend** — Semua berjalan di browser

---

## Quick Start

```bash
git clone https://github.com/alfindigital/wa-link.git
cd wa-link
npm install
npm run dev
npm run build
```

---

## Stack

- TanStack Start + TypeScript 5
- Tailwind CSS + shadcn/ui
